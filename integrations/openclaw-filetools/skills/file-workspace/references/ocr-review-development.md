# OCR复核：仅独立开发实验

本说明没有新增OpenClaw工具，也不代表生产Worker提供PP-StructureV3、图片预处理或空间恢复能力。不能虚构 filetools_extract 配置或提交整套生成/识别器绕过生产沙箱。生产调用先核对真实已部署能力；用户未授权时不更换OCR、不安装依赖或调整限额。

已实现的开发入口：仓库 `scripts/review_ocr_layout.py` 读取既有PP-StructureV3原生JSON及Markdown；`scripts/evaluate_ocr_review.py` 做结果层回归/参考CER；`scripts/prepare_ocr_preprocessing.py` 生成少量实验副本。这些是独立测试脚本，不能冒充正式任务、发布回执或QQ交付。

复核必须分别观察原图、overall_ocr_res文字/坐标/原生识别分、parsing_res_list及最终Markdown。空间覆盖处理换行、标点、重复文本和块拆合；可靠恢复须有局部位置及顺序锚点。无法可靠定位的已识别行与原页/区域关联为待核对片段，保留相关原文和理由，不猜题号、不补题干、不静默丢弃。恢复后检查重复、阅读顺序、跨栏及选项归属；覆盖增加不等于文字准确。

识别分必须注明真实引擎来源，不是正确概率；结构遗漏、重复、次序、题号和选项告警独立记录，数字/否定词/编号属重点风险。高分不能覆盖遗漏或关键文字分歧。复核状态为通过、需复核、无法确定；未有真实人工确认，不把无告警或开发Agent看图当成用户确认。后续视觉/人工记录保留审阅者类型、范围、证据和处理结论，不新增自报置信度作为真值。

预处理原图只读、输出副本，参数、图片SHA及坐标变换须留档。仅比较已授权页面，使用相同看图参考及CER口径，不用模型纠错、两套OCR一致性或更流畅的输出替代参考。分歧只提示复核；效果退化保留，不默认替换原结果。当前两种实验方案未证明普遍收益。

复核记录/全文/原图留独立审计及忽略目录，原OCR不覆盖。正式工具的登记、FILETOOLS_INPUT、受限执行、发布和附件回执规则不变；无用户明确授权不永久保存、不导入知识库。完整配置和测试说明在仓库 `docs/OCR_REVIEW_EXPERIMENT.md`，本轮证据边界在 `docs/OCR_SPATIAL_REVIEW_REPORT.md`。
