# OCR复核：仅独立开发实验

本说明没有新增OpenClaw工具，也不代表生产Worker提供PP-StructureV3、图片预处理或空间恢复能力。不能虚构 filetools_extract 配置或提交整套生成/识别器绕过生产沙箱。生产调用先核对真实已部署能力；用户未授权时不更换OCR、不安装依赖或调整限额。

已实现的开发入口：仓库 `scripts/review_ocr_layout.py` 读取既有PP-StructureV3原生JSON及Markdown；`scripts/evaluate_ocr_review.py` 做结果层回归/参考CER；`scripts/prepare_ocr_preprocessing.py` 生成少量实验副本。这些是独立测试脚本，不能冒充正式任务、发布回执或QQ交付。

复核必须分别观察原图、overall_ocr_res文字/坐标/原生识别分、parsing_res_list及最终Markdown。空间覆盖处理换行、标点、重复文本和块拆合；可靠恢复须有局部位置及顺序锚点。无法可靠定位的已识别行与原页/区域关联为待核对片段，保留相关原文和理由，不猜题号、不补题干、不静默丢弃。恢复后检查重复、阅读顺序、跨栏及选项归属；覆盖增加不等于文字准确。

识别分必须注明真实引擎来源，不是正确概率；结构遗漏、重复、次序、题号和选项告警独立记录，数字/否定词/编号属重点风险。高分不能覆盖遗漏或关键文字分歧。复核状态为通过、需复核、无法确定；未有真实人工确认，不把无告警或开发Agent看图当成用户确认。后续视觉/人工记录保留审阅者类型、范围、证据和处理结论，不新增自报置信度作为真值。

预处理原图只读、输出副本，参数、图片SHA及坐标变换须留档。仅比较已授权页面，使用相同看图参考及CER口径，不用模型纠错、两套OCR一致性或更流畅的输出替代参考。分歧只提示复核；效果退化保留，不默认替换原结果。当前两种实验方案未证明普遍收益。

复核记录/全文/原图留独立审计及忽略目录，原OCR不覆盖。正式工具的登记、FILETOOLS_INPUT、受限执行、发布和附件回执规则不变；无用户明确授权不永久保存、不导入知识库。完整配置和测试说明在仓库 `docs/OCR_REVIEW_EXPERIMENT.md`，本轮证据边界在 `docs/OCR_SPATIAL_REVIEW_REPORT.md`。

## 离线复核包与质量筛查（增量开发实验）

新增真实开发入口是 `scripts/build_ocr_review_bundle.py` 和 `scripts/import_ocr_review.py`，仅处理显式checkpoint中已授权页面。它们尚未接入生产FileTools，不是新注册工具、附件发布或QQ交付能力，不用exec绕过受限处理。配置为版本化 `deploy/ocr-screening-v1.json`，记录版本/哈希；参数不等于用户确认，附件配置不能作为生产模板/脚本执行。

原图质量、原生识别风险、结构完整性分别报告，未检查/证据不足为未知。指标及分数不是正确概率，不合成准确率；高分不能抵消正文遗漏、关键文字分歧或源图受损。没有报警不等于核实。源图人工也看不清时记录区域为“原图无法辨认／需要更清晰来源”，不能靠上下文补写，也不能用模型一致性作参考真值；预处理仍默认关闭。

离线包初始未确认，包含原图区域/整页、文字、风险原因、来源、恢复依据和状态，可筛选并导出确认JSON，由开发侧核对真实审阅者类型后导入。导入校验原图/OCR/修订哈希、版本、ID、操作和目标；拒绝过期/重复/冲突，建立新修订副本和历史，不覆盖原OCR。开发Agent记录不能冒充用户确认。单项文字确认不解决未知位置，也不代表整页通过；整页仍须明确人类全页确认且无未解决结构阻塞。不可辨认处仍保持未知，不为得到通过而强行猜补。

视觉复核记录字段仅预留，本轮没有模型依赖或外部调用。完整规则、参数范围、使用与导入限制见仓库 `docs/OCR_OFFLINE_REVIEW.md`。永久保存、知识库授权、录音原转写及正式产物回执规则保持。

## 显式授权的M3五页对照（后续增量实验）

上节“没有外部调用”为离线包阶段历史边界；后续仅在用户明确授权的五页范围，用现有minimax-portal/MiniMax-M3渠道做真实图片实验，仍未接入生产FileTools。仓库prepare_m3_ocr_comparison.py准备独立提示及裁片，evaluate_m3_ocr_comparison.py对照，build_m3_comparison_demo.py复用离线复核包；不是新正式工具或调用参数。未经授权不发送业务图片，不切换供应商或身份，不提交密钥/原响应。

确认工具实际传入原生图像块及尺寸，不能把路径、模型自报已看图或自报尺寸当图片证据。直接转写不输入OCR/参考/历史风险；疑点复核按固定程序规则选区，单独计入整页质量评价、重复图片、失败/重试和可见用量。模型质量自评与转写同次发生，不称独立验收；图片缩放、无效结构/坐标、未知覆盖必须留记录。模型分项等级经版本化配置得到实验可读性分，不是准确率。源图不可辨认不猜补；高分不能抵消遗漏、关键文字分歧和顺序阻塞。

模型keep、改字和质量评价不作为用户确认；仅保留未确认衍生结果及前后依据，原OCR/历史不变。正常抽查建议不等于人工通过，候选缩减须有实际漏报检查证据；不能靠忽略格式或未知项宣称减少人工。费用未知则标不可得，SDK cost=0不代表免费，按量价估算和套餐实际消耗分开。开发结论与剩余边界见docs/OCR_M3_COMPARISON_REPORT.md；录音、发布、永久保存和知识库授权规则均保持。
