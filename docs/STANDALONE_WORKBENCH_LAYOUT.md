# 对照工作台布局：功能入口清单

本轮基于执行时最新远端83470b8，仅重构布局与为此必要的交互保护，不扩展OCR、段落坐标、模型疑点或模板生成能力。

| 保留功能 | 新入口 | 保护约定 |
|---|---|---|
| 返回项目 | 顶部返回 | 有文字草稿先保存/放弃/取消 |
| 左右文件切换 | 顶部各侧文件选择 | 右侧切换保护文字草稿，左侧切换不重建右侧编辑器 |
| 左右位置输入及上一/下一位置 | 顶部紧邻各侧文件 | 明确原件物理页/文字位置/输出页，面板关闭仍可用 |
| 原件查看/下载 | 各侧文件菜单与正文链接 | 已登记原文件，不改写 |
| 编辑、保存、取消 | 顶部右侧操作 | 默认阅读，无独立编辑栏；仅编辑时显示保存/取消及状态 |
| 历史只读、恢复后编辑 | 顶部历史状态与恢复入口 | 追加新版本，不改写历史 |
| 模板导出 | 顶部导出 | 明确当前选中文字版本，草稿保存/放弃/取消 |
| 评论对象、评论保存/清除 | 辅助面板：评论 | 保留本地草稿、服务版本冲突和独立对象绑定 |
| 评论JSON导入/导出/冲突处理、审阅者声明 | 辅助面板：评论 | 既有回执协议不变，不新增审核状态 |
| 原件位置、质量记录及质量筛选 | 辅助面板：原件与筛选 | 原图质量属于原件，不表示转换准确率 |
| 提取错误与评论筛选 | 辅助面板：原件与筛选 | 改变文字位置前保护草稿 |
| 按原件页定位、多片段候选 | 辅助面板：原件与筛选 | 仅使用已登记映射，不猜坐标/页码 |
| 历史版本、差异、查看与恢复 | 辅助面板：版本与差异 | 查看不改数据，恢复追加新版本 |
| 左右缩放、阅读/Markdown源码、专注及窄屏切换 | 辅助面板：阅读设置；窄屏顶部切换 | 左右独立；打开关闭面板不重新渲染或清空编辑内容 |
| 项目、当前产物、来源评价、诊断 | 辅助面板：技术详情 | 技术信息按需查看，不常驻底部或正文 |

布局验收与部署记录将在完成实测后补充。私有真实页面截图仅放交付包，公开证据只用合成内容。

## 布局与交互

顶部单一操作区域承载导航和编辑/导出，不再保留旧版展开工具栏、正文内编辑栏或底部反馈栏。桌面左右文档各自滚动；辅助面板占用独立列。900px及以下面板转为下方分区，600px及以下通过顶部“左右切换”查看单侧文档与对应位置输入。面板不浮盖正文，关闭后返还空间。阅读字号保持14px，编辑字号15px。

面板开关不重新渲染正文或编辑器。面板导致原图缩窄、滚动上限下降时，保留打开前位置，关闭时恢复；面板打开期间主动滚动则保留新的位置。编辑器内容、选择范围和内部滚动保留。每次进入均为阅读、面板关闭，不恢复旧版专注/展开状态。

历史文字有明确只读标记，可从顶部“恢复后编辑”追加恢复版再编辑，也可从版本分组查看差异/恢复。保存失败保持草稿；保存期间禁用切换和脏稿对话框其他操作。进入编辑会使尚在加载的阅读正文失效，防止异步正文追加到编辑器。

## 实际验证

- Linux容器、Python3.12、LibreOffice7.4.7.2、Droid Sans Fallback中文字体；Chromium140.0.7339.16，CSP保持启用。
- 137项相关Python测试通过（文字修订、HTTP、对照、页码/预览、上传分析、批处理、模板导出、离线项目）；5项既有SWIG弃用警告。
- 所有对照JavaScript语法检查、两个浏览器验证脚本的Ruff检查通过。
- 合成169页PDF只直接提取6–10页，不调用OCR/模型。浏览器覆盖上传、评论保存与JSON往返、原图质量/错误/评论筛选、来源定位、原件下载哈希、当前修订Word导出、历史版本7–9页PDF导出、独立预览下载与回收恢复、离线包更新。
- 工作台专项覆盖文件/页码/筛选/阅读设置/取消编辑的草稿保护，模拟保存503失败后草稿保留，历史只读→恢复新版本→编辑保存。面板开关不丢正文滚动、编辑内容、光标或编辑器滚动。每次进入默认阅读、面板关闭。
- 1366×768、1920×1080、1024×768、768×900、390×844、320×640实测；无页面横向溢出，面板与正文无覆盖，窄屏编辑及导航可用。

真实截图在原图与文字完成加载后采集；私有截图仅进入交付包。公开仓库的[截图与结果](evidence/workbench-layout-20261011/)全部使用合成PDF。原项目仅阅读；修订等破坏性验证只在合成项目/隔离副本进行。

## 已有项目与离线包

在线旧项目的HTML/JS/CSS从服务源码提供，读取project.js时刷新查看器资产；不改写原件或文字正文。重新下载离线项目时重新发出查看器资产，原件/文字哈希保持一致。此前已经下载到用户设备的离线包不会远程改变，需要重新下载；新版离线包阅读、评论JSON及禁用服务器写入行为保留。

复现：先运行`check_template_export_browser.py BASE_URL EVIDENCE_DIR`创建合成项目，再运行`check_workbench_layout_browser.py BASE_URL EVIDENCE_DIR/layout PROJECT_ID`。后者拒绝对不含“合成”的项目名运行修改验证。应使用fixture-only隔离服务，禁止用业务项目运行修改测试。

部署实测发现并修复：导出列表闭包可能保留预览生成前的产物快照，即使后台已完成，首次点击仍显示生成中。打开独立导出预览时读取当前产物状态，使用请求序号防止快速关闭/切换时旧请求插入另一文件。增加明确传入“RUNNING且无预览页”旧快照的浏览器回归，要求实际完成的图片正常加载；不改变生成能力或正文。

日常部署对象：`filetools-http-dev-review-r3` / `127.0.0.1:18971`，源码为当前开发分支，只重启该服务；保留既有数据根、配置和镜像。部署前无活动任务，备份36个项目元数据并记录373个已登记文件哈希。部署后原有373个文件无变化；合成验收项目另行追加。完整部署证据与私有前后截图在交付包。
