# 文字版本与模板导出

上传原件创建项目 → 提取文字 → 对照与修改 → 选择模板 → 导出 Word/PDF。

新提取任务默认只生成文字，修订保存只追加文字版本。从文字行或对照页点击“导出”选择文字版本、已发布模板、Word/PDF（可单选或同时选择）、原件页范围和分页方式。从对照页进入时默认选中正在查看的版本；有未保存修改时必须选择保存、放弃或取消。保存失败仍保留草稿。历史稿可直接导出，编辑须先恢复为新版本。

“全部”指所选文字版本全部已有内容。例如原件169页而文字只有6—10页，全部只导出6—10页；7-9只导出这些来源页；11提示没有文字记录。范围按原件物理页，不按文字片段序号。同一来源页的全部片段保留；缺少可靠映射时禁止按范围导出。没有分段映射的旧文字稿仍可全文导出。全文与分段记录不一致时拒绝导出，避免遗漏文字。

“按模板自动分页”允许自然跨页。“尽量保持原件分页”需要完整映射；会按实际 LibreOffice 渲染验证来源组，空白页保留。内容放不下时可选择适配字号（有字号下限）或允许续页，否则报告冲突。不会截断文字，也不保证任意内容一原页对应一输出页。

原件、文字版本、导出文件分区展示，业务对照只列原件与文字；模板合成预览仍可比较 Word/PDF。导出文件独立预览、下载、改名、回收与恢复。JSON、质量评价、评论和技术诊断单独保留，不进入普通文件列表和正文。不增加审核状态。

每次导出追加任务、文件ID和路径；失败/取消不登记导出文件。任务及 `export_source` 记录来源文字ID、SHA256、版本、实际来源页、请求范围、模板版本/哈希/快照路径和分页策略。排队时即固定模板快照；导出不访问识别适配器。两种格式内部均生成并校验，未选择的格式仅作为诊断保留，不显示为导出文件。

## 接口

`POST /api/projects/:pid/document-exports`：

```json
{
  "source_artifact_id": "已登记文字版本ID",
  "template": {"id": "questions-zh-cn", "version": "1.0.0"},
  "formats": ["docx", "pdf"],
  "pages": "7-9",
  "pagination": {"mode": "continuous", "font_fit": false, "minimum_font_pt": 9, "allow_continuation": false}
}
```

返回202及任务ID。`pages` 默认“全部”，`formats` 默认两种；分页可选 `continuous` 或 `source-pages`。旧 `/format` 和任务级 `/tasks/:tid/format` 接口保留，已有数据不删除。显式传入旧内部任务参数 `generate_documents=true` 的调用仍兼容；新任务未显式提供该参数时，即使旧配置为true也默认只生成文字。

## 已有项目与离线包更新

在线管理页从当前服务源码加载；对照页的 HTML/JS/CSS 也由服务直接提供当前资产，无需覆盖原件。访问 `review/project.js` 或下载离线项目包时，现有 `emit_viewer` 会更新项目入口、评审资产和数据镜像，保留原件、文字、导出文件及评论历史字节。现有ZIP不会自动修改，需重新下载离线项目包。离线允许阅读与评论草稿导出；修订保存及模板导出需在线服务。

更新独立开发服务时保留原数据根，仅重启该服务；不要改动 NAS/OpenClaw 服务。验证及截图见 [本轮验证记录](STANDALONE_TEMPLATE_EXPORT_REPORT.md)。
