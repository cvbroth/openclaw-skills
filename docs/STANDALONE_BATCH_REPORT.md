日期：2026-10-09，基线7611f3eb15a9c52645fa6a53c8f208585ccf1550。实施前说明STANDALONE_BATCH_PLAN.md；接口、限制与回退见STANDALONE_BATCH.md。保留既有OCR、模板、私有设置和评审；仅独立开发服务更新，生产、OpenClaw、知识库及原件不变。

## 实现范围

严格共用范围解析器支持5-150、1,3,8-20、全部及中文逗号/空格，去重排序后核验原件页数与单任务上限。配置校验、示例与实际开发配置均改为单任务最多1000页；上传512MiB、PDF总1000页保持。依旧单队列逐页执行/保存，显式取消/继续，没有整册一次送模型或自动重试。

任务入口在任务区顶部；活动优先、其他时间倒序，历史和归档默认折叠，初次各10项，后续按10项加载。逐页表格打开后只显示50条，保留输入节点及details节点；当前API仍读取完整元数据，不声称服务端分页。阶段区分逐页提取、生成文档、登记及独立预览。

产物短名称与来源页范围、方法、模板、版本/时间分离；结构是否核对另提示，内部ID/路径/哈希不变。显示名与下载名可改，回收/恢复只调整元数据，依赖、评论和旧产物保持。任务归档不回收结果，活动任务不能直接归档，原件回收走项目级操作。评审入口移入产物区域，稳定ID深链支持精确右侧产物、两个产物对照、双方独立locator。没有真实映射不推测输出页对应原页，未知/回收ID明确提示。
