# 独立 HTTP 批量提取与管理

本轮基于7611f3e增量，仅更新独立开发服务。上传仍只创建项目和原件分析，不自动提取。单文件512MiB、PDF总1000页（含）不变；示例及开发配置的conversion.max_selected_pages现为1000，校验允许1–1000。旧自定义配置不会自动改写，需明确更新该字段。

## 选择与执行

详情任务区顶部“新建提取任务”：支持`5-150`、`1,3,8-20`、`全部`。中文逗号规范化，空格可分隔选择或放在范围/逗号旁。解析严格拒绝倒序、小数、非整数、空项、零与越界；去重排序后显示实际页数，以原件物理页为准。服务端共用parse_pages验证，JSON仍接受整数列表，去重排序，不仅依赖浏览器。

`POST /api/projects/:pid/tasks`例：`{"engine":"pdf-text","pages":"1,3,8-20"}`。全部不超过原件页数和配置上限。保持单队列、逐页渲染/执行/落盘，不同时渲染整册，也不合成一次整册模型请求。失败没有自动重试。大批量远端启动和继续前显示页数、方法及可能消耗额度，费用/余额未知，必须明确确认；取消确认不会创建任务。不承诺剩余时间。

任务识别阶段与文档生成阶段分开记录phase；产物保存后预览继续走既有队列，页面显示预览排队/处理中/失败，不把所有识别页完成当作所有产物完成。取消保留已完成页和attempt，重启中断不自动发请求；显式继续只重试非SUCCEEDED页，旧成功页不重跑。生成失败但文字已保存时，可复用已有文字重新排版。每页超时、线程、容器约束不变，单次文档生成仍60秒，千页Word/PDF完整生成未据此保证。

活动任务优先，其他按创建时间倒序；历史和归档默认收起，初次各10项，再显示10项。逐页表格打开才建立，50行一批。表单独立于列表轮询，保持输入、展开、选择、滚动；不会每两秒创建千行表格。当前API仍返回完整元数据，DOM按需显示，不声称服务端任务分页或极大项目零内存成本。

## 产物和回收

主名称为原件、提取文字、Word排版稿、PDF排版稿；来源页范围、方法、模板、版本、创建时间单列。题目结构是否已恢复单独提示。版本取实际登记版本（提取任务内结果版本，不同任务可同为第1版），任务/时间和稳定ID区分不同结果。下载名使用项目名_显示名_版本.扩展名，服务器存储路径及内容不因改名变化。

- `PATCH /api/projects/:pid/artifacts/:aid`：`{"name":"我的排版稿"}`或`{"recycled":true}`/false。
- `POST /api/projects/:pid/tasks/:tid/archive`：`{"archived":true}`/false。

回收只是带历史的元数据状态，不删除文件、来源依赖、评论或旧回执；默认列表及评审选择器不展示回收项，产物回收站可恢复。原件可改显示名，回收必须使用项目级操作。存在活动转换或目标预览时拒绝管理操作，先取消或等待终态。任务归档与产物回收独立，不删除结果。回收文字不能用于新排版，回收文档不能启动新预览；已存在子产物与溯源继续保留。技术JSON保留完整记录，回收不是访问权限撤销或永久删除。

## 精确评审与迁移

评审入口在“内容与产物”及每个可预览产物旁。“查看 / 对照”使用`review/index.html?right=<artifact_id>&left=<reference_id>`；可选择两个产物，URL保留双方ID及各自locator JSON，刷新/返回/离线包均沿用。左侧默认原件，仅在当前来源映射明确、且原件已有匹配位置时定位；输出页码不映射成同号原PDF页。没有映射或没有原件预览时显示独立定位/不可用，可使用原文件入口，不伪造页面图。

回收、未知ID或失效定位明确提示，不能把另一版本预览称为目标成功；错误链接保持到用户重新选择/打开正确链接。评论仍绑定ID、哈希、定位，名称与回收不改变身份。离线包包含全部登记依赖和可恢复回收标记，选择器同样隐藏回收项；没有服务器不能执行恢复，须回开发服务恢复后再导出。

旧本地登记原件缺少bytes时，详情在已登记受限路径读取stat补齐，不扫描外部引用。大小显示可读单位和精确字节；不可访问外部引用仍明确未知。展示层迁移不搬动文件。

凭据仍由私有设置写入，启动时冻结、内存传递；新增专用FILETOOLS_ENGINE_CREDENTIAL子进程环境通道，兼容旧环境引用，明确清除会阻断回退。项目请求诊断只留脱敏快照，不保存密钥。CREDENTIAL_UNAVAILABLE表示本地准备阶段拿不到配置凭据，不能解释为远端欠费/拒绝；历史诊断被脱敏后不能反推当时内存环境。真实云端验证不在本轮默认范围。

## 验证、交付与回退

`scripts/simulate_standalone_batch.py`仅合成测试替身，不注册到正常引擎清单；替换渲染和子进程，使用真实串行执行器/发布/恢复。附加历史卡片夹具未实际执行。该测试不表示1000页真实OCR或Word/PDF成功。浏览器脚本仅对合成两页直接提取，其他复用已有产物；无云端调用。

升级前等待终态，私有备份开发配置/项目元数据与旧代码，调整max_selected_pages并重启独立开发服务。回退可恢复旧配置/代码，保留新增产物、评论及回收历史；旧界面不理解回收标记，可能显示回收项，不应以旧整库覆盖新文件。恢复状态可先用当前版本逐项恢复/取消归档再回退。生产、OpenClaw、OCR后端与公共模板均未改动。
