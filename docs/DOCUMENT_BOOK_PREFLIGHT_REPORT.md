## 可复用实现与模板

- `document_sample.py`：来源显示由`show_source_labels`控制。隐藏只省略正文Source展示；语义题目分组仍独立，原文、原页、完整结构和修订记录不删除。Word、PDF分别使用自身真实分页能力。
- 实际Word预览发现keepNext链在无末尾Source时仍会拆短题。隐藏来源版本对实际测量的短题使用成熟python-docx单元格行与原生cantSplit属性；只限制短题，长题仍是可跨页的普通段落。真实空分隔段避免相邻短题表格被合并成大排版单元，语义核对遍历真实正文及单元格，不能只读Document.paragraphs而漏掉内容。
- `document_layout_checks.py`及`render_document_sample.py`：支持无Source的语义组及有界题目行，检查正文和页脚；来源跟随规则仅在实际显示来源时适用。检查长题、短选项及正文顺序。
- `src/nas_filetools/templates/drafts/questions-zh-cn/1.1.0.json`：新增可校验草稿，来源显示false，输出页数防循环上限1000。这个上限不是CPU/内存/输出限额或60秒沙箱限制；不调整生产限额。`schema.json`兼容旧版本缺少布尔字段时默认true。1.0.0文件及SHA保持不变，catalog默认与published列表未变，草稿不能在生产选择。
- `structure_ocr(..., mixed=True)`是开发实验模式：识别候选多选/材料结构、题型切换、章节题号重置、有序同行选项并保留原文片段映射；未通过真实整册结构验收，不能当作生产能力。生产入口仍只接受reviewed-single-choice-v1，增量添加明确拒绝其他题型的检查，避免无声套用单选模型。该拒绝检查也尚未部署。
- `scripts/document_book_preflight.py`：显式输入及范围的独立开发预检，核验来源页标记，输出逐块原页/原文与独立疑点。不是新工具，不扫描目录，不发布或保存。
- Skill及reference：正式正文可配置隐藏来源、审计必须保留；已有全册授权不重复确认；检查真实题型、接口与范围，区分实验模式、正式入口和生产部署，不编造参数。
