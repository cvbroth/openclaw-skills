# HTTP 对照评审 R2 实测报告（2026-10-09）

基于7adf92bc6e2e22401baf6136c458daf25a7cb65c增量修复。实施前布局说明见 STANDALONE_REVIEW_R2_PLAN.md，数据规则见 STANDALONE_REVIEW_R2_MIGRATION.md。本轮没有新增 OCR、云端请求或正文生成；原始识别及 Word/PDF 字节保持，公共模板不改，只更新独立 HTTP 开发服务。R1 的下载入口、浏览器 object 及开发目录离线渲染不能算产品内 Word/PDF 对照预览通过；本报告替代该验收边界。

## 完成的改动

原图质量从 Markdown 页属性迁为独立集合，带源版本/页、实际传图SHA/尺寸、模型/任务/时间/依据。页面去重保留任务来源，多次评价可选；缺评价和旧来源不明分别保留。原图质量仅筛源页，与右侧产物、远端/本地错误及产物评论筛选分离。原图评论和当前产物评论具有显式对象，不混进正文。

新增 previews/preview_worker，使用同一受限串行执行队列及独立子进程。DOCX→LibreOffice实际PDF→PyMuPDF页面PNG；PDF→PyMuPDF页面PNG。源DOCX哈希、渲染器、派生PDF哈希、参数与日志可核对，没有借用另一个PDF产物。缓存按 SHA/版本/参数，失败有真实异常和重试，已保存正文不受影响；重启中断可恢复。缺资源的历史项目仍能打开，预期哈希不抹去，缺图明确报读取失败。

列表使用紧凑卡片、搜索、用户/历史验证区分、主要上传操作；详情 `/projects/<id>` 独立地址。详情提供任务、最新版本优先的产物、设置和折叠诊断。评审工具栏分组，原件和任意产物两侧独立翻页/缩放/滚动，评论可折叠，窄屏切换保留草稿；技术信息默认收起。源物理页、上传图片位置、Word/PDF输出页明确区分，不伪造同步映射。HTTP与离线包使用同一项目数据和预览。

## 实际渲染

复用已存在独立镜像 `sha256:3bf4eabd2e4cde9521c212568359f416c6ab9d06709f3d677e8cdaa84efe8530`（原文档验证镜像），不向生产安装。Word预览运行依赖 LibreOffice Writer **7.4.7.2 40(Build:2)** 和既有中文字体；PDF预览运行依赖 PyMuPDF **1.25.5 / MuPDF1.25.6**。这是新增的开发服务运行依赖，纠正R1“LibreOffice仅测试依赖”的说法。Poppler/PDFium/Chromium不进入服务运行依赖。使用现有2CPU/4GiB、memory-swap4GiB、UID1000、只读根容器；预览子进程不继承模型凭据，LO阶段120秒/整体180秒期限，120dpi，单页20M像素/1000页上限，未提高额度。

## 浏览器与测试

真实 Chromium **140.0.7339.16**，1600×1000/1440×1000及640×900。浏览器使用私有临时中文系统字体目录，产品CSS仍用系统字体；未注入远程字体或降低CSP。脱敏记录和纯合成截图见 docs/evidence/standalone-review-r2；私有真实截图在 runtime/standalone-http-r2/browser，不入Git。

- 点击项目→独立详情URL，刷新、返回保留搜索；评审→详情→评审保留两侧产物与位置。
- 第12页实际DOCX/PDF两页均图片解码、页面SHA匹配；Word第2页对PDF第1页、175%缩放，双向滚动互不改变，顶部y=0。
- 历史50页源质量good筛出29、unknown筛出14；切右侧原件/Markdown名单不变；远端错误仅影响右侧错误名单。样例无评价筛为unknown5。
- 合成项目原图/产物评论分别保存，重载、JSON导入导出、清除一个对象不影响另一个；错误项目回执拒绝。评价历史切换与窄屏草稿通过。
- 故意坏PDF真实 FileDataError，浏览器显示失败和重试按钮；实际重试仍失败、没有假预览成功，原件/正文保留。合成失败不属于真实试题文件失败。
- 第12页HTTP导出后解压移动，以file://实际打开Word/PDF两侧图片；当前DOM仅2张图。历史50页初始只加载当前原图，未同时解码50张。
- 明确重复请求已渲染预览命中验证过的缓存，未新增attempt目录；翻页和切换只读图片，不调用渲染。

最终37项相关测试通过（17.78秒，5项既有SWIG弃用警告）；涵盖HTTP/队列/模拟协议、旧反馈、原图关联/多记录/缺图/缺凭据、PDF真实预览/缓存/失败/重启、正文模板回归。适配器协议/故障注入是合成测试，不能混称真实OCR或远端供应商验证。Ruff及git diff --check通过；本轮云端和OCR调用均0。

## 使用与边界

服务仍只监听127.0.0.1:18971；Windows可 `ssh -N -L 18971:127.0.0.1:18971 chen@myserver`，打开 http://127.0.0.1:18971/ 。先进入第12页项目，在评审右侧选择最新M3 v2 Word/PDF，或左Word右PDF；质量只选择原图。下载包位置/大小/SHA见 evidence/standalone-review-r2/delivery.json；解压后打开根index.html，不需要HTTP服务器。包内已有预览可离线查看，离线不能运行渲染器。

未验证：Windows用户实际打开新包与下载、Microsoft Word客户端字体替换、所有浏览器/所有DOCX兼容性、任意大文档在180秒/4GiB的渲染能力。120dpi缓存不能提供无限细节，放大超过像素分辨率会模糊；需要原件时可打开原文件。没有可靠的源→输出页自动映射，保留手动定位；预览失败需明确重试，不自动触发付费识别。生产FileTools/OpenClaw/Skill/模板/额度未改，没有整册识别、永久保存或知识库写入。等待用户实际验收。
