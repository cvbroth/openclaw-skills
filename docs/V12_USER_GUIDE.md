# 普通用户使用

上传文件后，Agent确认登记完成。只上传没有问题时，它会等待你的要求。文件只进入自己的Agent文件区，不自动进入知识库。

可以直接说：“读这个PDF第2到5页，说明备份要求”“转写录音前十分钟并引用时间”“这张图识别印刷文字”“把表格指定单元格改好，给我副本”。Agent会按问题选择读取、OCR、转写或临时Python，重任务提供可查询的任务编号。图片识别不等于理解照片；手写、公式和复杂表格需要核对。

大文件建议指定页码/时间范围；你明确要求全文时才按全文处理。回答会引用页码/时间/正文块，说明未读内容和失败部分。识别不清不能被当成没有内容。

NAS长期文件可指定批准目录内具体文件，让Agent登记引用。上传请先写临时.part，完成后改成最终名；不需要另写JSON完成文件。文件变化后要登记新版本，不能把旧分析当新内容。

生成的MD/TXT可以直接读取，XLSX要实际取得文件。Agent会复用现有渠道发送能力；有成功回执才说已发。如果渠道限制或权限不足，它应告诉你原因，并给出保存目录供取回。拿到表格后建议打开核对修改位置。

缓存默认最后有效使用后保留72小时；原件快照和明确保存版本不会自动删除。你说“保存这份结果”即可保存独立版本，来源与图片一起保留。没有回复保存询问时仍是临时结果。缓存过期可以从原件重新处理，不必重复上传。

新会话可以明确选择自己Agent的历史文件；它不自动继承旧会话任务。main和chen即使属于你，也是不同文件区。当前群聊暂不开放文件工具，请使用对应私聊。

删除时明确说删哪个原件/结果/会话引用，活动任务先取消并等待终止。NAS reference删除只取消登记，外部原文件不删；保存版本保留。
