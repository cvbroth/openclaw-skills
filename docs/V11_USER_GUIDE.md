# FileTools V1.1 普通用户说明

每人使用自己的 Agent 和已绑定的 QQ 私聊。无需另建账号。群聊目前不开放文件权限；发到群里、转发别人的文件ID、在正文写服务器路径，都不能取得其他人的文件。

## 发文件与提问

单独发附件：Agent 归档后确认接收，等待你提出任务。正在归档时会显示处理中；尚未确认接收时不要把空列表理解为上传失败或内容为空。

附件和指令一起发送可以直接处理，例如：

- “这份 PDF 第 12–18 页有哪些备份要求？请引用页码。”
- “查看这份 Word 的设备表，保留表格前后的说明。”
- “识别这张截图里的印刷文字。”
- “转写这段录音，再单独整理会议纪要。注明时间范围。”

大文件会先检查总页数/时长与少量预览，按你的问题选范围；明确要求全文时按页或音频块处理。长任务有排队、进度和取消状态，不能保证 CPU 实时转写。可说“取消这次任务”；确认取消后才能清除正在使用的原件。

扫描/混合 PDF 的文字识别不等于完整还原，复杂表格、公式、手写、照片画面没有可靠识别保证。Word 图片会保留，但图中文字不会自动转写。没有识别出的内容会如实说明；部分成功只能引用已处理范围。音频逐字稿与模型整理的纪要分别保存。

## 临时、保存与历史文件

归档快照长期保留；处理结果默认闲置 72 小时后清理。有效读取会续期，单纯查询进度不会。完成有价值的结果后 Agent 适时询问一次是否保存；不回复仍是临时结果。一开始就说“处理后保存”会直接保存。

可以说“保存这次的纪要”“保存这份转写原文”“保存修改后的表格”。保存的是独立版本及所需来源/图片资源，清理缓存不影响保存文件。保存不等于导入私人或 Family 知识库。

换会话后可说“列出我以前上传的 PDF，选择名为……的那份”。Agent 列候选并明确选择属于你的历史快照，重新关联当前会话。旧会话任务不会直接开放；缓存过期可从快照重做，无需再次上传。

可以查看“我的文件和容量”“已保存成果”。编辑后的 XLSX 可以保留原格式；本版二进制读取返回文件信息，没有实现自动通过 QQ 发回文件。需要取回时由管理员提供只读保存区交付方式，不能开放整个服务数据根或别人的 Agent 目录。

## 删除的范围

“删除这份原件”作用于唯一选中的归档快照及其全部上传引用，保留已保存成果，并标注其原件已删除。同名多份内容会先列候选。“移除当前会话引用”不会删实际快照。“清理这次处理缓存”不会删原件或保存成果。工具不会删除手机、QQ 渠道文件或 Samba inbox 中你放入的原文件。

## QQ 放不下的大文件

QQBot v2.0.3 已核对的下载调用限制为 500 MiB、120 秒；这是插件实现设置，不是 QQ 平台保证。文件服务归档上限默认 4 GiB，超过 QQ 入口的文件走管理员给你的 Samba inbox 共享。

1. 向自己的 inbox 上传 `recording.wav.part`。
2. 完整上传后改名为 `recording.wav`，之后不要修改内容。
3. 在同目录放 `recording.wav.ready`，内容为实际字节数和完整 SHA-256。标记也先写 `.tmp` 再改名。
4. 告诉 Agent：“查看我的 inbox，登记这份录音并转写。”

在 Windows 对已完整上传的文件生成标记示例（路径替换成管理员提供的个人共享）：

```powershell
$inboxFile = '\\NAS\chen-inbox\recording.wav'
$readyData = @{
  bytes = (Get-Item -LiteralPath $inboxFile).Length
  sha256 = (Get-FileHash -LiteralPath $inboxFile -Algorithm SHA256).Hash.ToLower()
}
$readyTemp = $inboxFile + '.ready.tmp'
$readyFinal = $inboxFile + '.ready'
[System.IO.File]::WriteAllText($readyTemp, ($readyData | ConvertTo-Json -Compress), [System.Text.UTF8Encoding]::new($false))
Move-Item -LiteralPath $readyTemp -Destination $readyFinal
```

未完成或哈希不符会拒绝登记。4 GiB 是接收限制，解析仍受独立页数、时长、解压、像素和输出限制。原生 QQ 语音若渠道只给 URL/已有转写而无可信本地原始音频，无法可靠归档；请改发音频文件附件或使用 inbox。

## 暂不支持的表格操作

例如“给这个 XLSX 增加 Double 列，将 Amount 乘以 2，保留 Notes 工作表”。Agent 会先说明将生成临时 Python 处理，再在副本上执行，检查目标行列/数值并保留脚本与来源，不改原件。无需为已明确授权的操作再次确认。

生产脚本环境需要 Linux 权限隔离和资源限制。缺依赖、无法隔离、超时或输出校验失败会明确报告，不会自动联网装包。公式缓存、宏、图表和复杂版式的保留需要具体核对；不能把未计算的公式结果当零。
