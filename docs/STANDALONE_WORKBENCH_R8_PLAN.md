# R8 实施计划及边界

基于 R7 3535ae73897d577af220f6523f365453e61a1212，当前测评分支工作区干净；复用 R6 按需预览、R7 修订保护、模板草稿/发布及真实 LibreOffice 渲染。仅独立开发服务，无 OCR/云端调用或生产变更。

1. 工作台：每次默认收起高级工具/评论/详情，保留两侧文件、可输入位置、页数和缩放。评价改布局内有界面板。基于登记映射提供来源页候选定位，接入 R7 未保存保护。
2. 模板页：分组响应式参数，明确载入/未保存/草稿/发布状态；保存选中真实版本，未保存禁止预览发布；字段定位报错。
3. Word样式导入：限量读取无宏 DOCX/DOTX 的 OOXML，处理继承、默认值、中西字体、行距与节设置；不执行附件。多节必须显式选节，缺字体必须选替代。仅提取可由生成器执行的兼容扩展；保存原文件和提取报告，草稿关联来源。
4. 来源分页：独立于模板的任务参数。只接受可靠物理来源映射，按来源组分页、不插入项目标题。单组实际DOCX渲染检测、有限减间距及可选字号下限，无法容纳明确冲突或显式允许续页。合并为同一DOCX后由其生成PDF，并逐来源组验证最终映射；空来源保留空页。旧连续模式保留。
5. 合成样本、已有授权密集中文样本和真实浏览器验证；区分故障模拟、真实文件渲染和未验证。ZIP相对路径/CRC/搬移离线浏览，实际Windows环境不可用则不冒称通过。Git仅通用代码、合成证据和脱敏报告。
