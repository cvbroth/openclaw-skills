## 格式与追溯

原生JSON保留layout数组/真实bbox，原生Markdown保留，逐调用原始文字及token另存。官方_format_block_content会strip、添加标题标记等；result2md还strip各块并过滤U+FFFD。这些是工具本身的导出行为，不当作开发侧原文修正；必要时以原始逐调用文本对照。适配仅复制原生MD、原生文字/坐标及图片引用；原始目录保留，不覆盖任何旧结果。

官方管线在结束时删除临时preprocessed目录，原尺寸warp中间页没有作为最终原生产物提供；本轮保留实际每次load_image后prepared PNG、grid/tensor形状和工具实际导出images资源，不重建或伪造已删除中间页。原始PNG仍在images目录。所有可见模型内部图像处理与原图不同之处按记录说明，不称模型直接按原始文件像素无变换处理。
