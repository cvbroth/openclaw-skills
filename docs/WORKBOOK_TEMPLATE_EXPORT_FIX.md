## 分页校准

原件184页，纸张A4（595.276×841.890 pt）。可见页面是扫描图，PDF内PingFangSC-Light文字层为type=3（不可见），不能把其字号当成印刷主体字体；不伪报原件字体名。可见原件主体以明/宋体观感为主，短选项常按两列布置；当前可用主字体仍为Droid Sans Fallback，不宣称字形与原件完全相同。

旧模板：A4、四边1.5cm、11pt正文、1.15倍行距、段前后0、标题11/12/11.5/11pt、标题段前2pt、选项缩进0.55cm/悬挂0.35cm。零段距已存在，不能把问题全部归因于段间距。主要损耗是每个短选项独占一行，以及全角缩进/字面Markdown空行未能按展示段落处理。

新可导入模板：`docs/templates/xiao-1000-compact-a4-1.1.0.json`。保留A4、1.5cm页边距和11pt正文；行距1.05倍，段前后0、标题段前1pt；明确A–D且适合半栏宽的AB/CD短选项两列，长选项独占完整宽度；表格单行防拆分，不再把整道短题封进不可拆的大行。字面Markdown的#、**等原字符保留，空行以段落布局表达，未重写原文字版本。

适配顺序：按模板原字号 → 去额外间距 → 用户明确允许后每次降低0.5pt → 到指定下限；本轮下限10pt。达不到单页时明确来源页和实际页数；允许续页仍是独立显式选项，不自动开启。合并来源组改用下一真实段落的pageBreakBefore，避免额外空段落吃掉一行；合并后逐输出页与独立来源组全文比对，不凭总页数判断对应关系。

50页验证中额外修复：长题干不能作为Word核心标题元数据（255字符限制），正文保持完整；按来源页导出的Worker超时随片段数有界增长（最多30分钟），支持50页/整份已有文字的实际逐组Office渲染；取消机制保留。旧模板1.0.0未覆盖，1.1.0为新版本。
