日期：2026-10-09。基于19ab5f44b856b204fdb0a9a19643a1126547a143增量，保留后续工作及全部历史OCR/模板/评论。实施前说明见 STANDALONE_UPLOAD_ANALYSIS_PLAN.md；接口、迁移、限制及回退见 STANDALONE_UPLOAD_ANALYSIS.md。生产、OpenClaw及知识库未修改。

## 已实现与真实验证

首页只上传建项目，流式64KiB落盘；浏览器观察“上传进度：0%/100%”后“正在检查文件（尚未启动转换）”，进入独立详情。创建后tasks为空，不调用引擎。后台原件分析独立逐页保存、登记诊断JSON，最终状态以保存登记为准。异常文件保留项目与原件，明确失败，重试分析不创建识别任务。超上限拒绝并清理临时文件。

使用自制五页PDF：文字、扫描图、带OCR层扫描、文字加小插图、空白。实际分类依次为text、scan、mixed、text、blank_or_undetermined；这是自动启发式分类与合成构造的对照，不是书籍正确率。样例、原件SHA及物理页码实际保存，未知信息未填默认值。JPEG实际类型、图片尺寸、密码保护和像素超限也有测试。没有渲染整册分析、没有模型调用分析。

实际HTTP直接提取选定第1、3页，Markdown/结构映射保留PDF原生点坐标与顺序；每页子进程墙时约0.209/0.207秒、峰值RSS65936KiB。没有产生视觉质量评价，没有运行图像识别。实际生成Word/PDF并分别使用已有真实渲染链预览，浏览器两栏确实显示页面。该合成普通文字输出标为保真片段，不冒充已恢复试题结构。

用户显式启动一张小型合成图的RapidOCR本地识别真实通过：rapidocr-onnxruntime 1.4.4、ONNX Runtime 1.20.1、既有固定模型、2线程，墙时1.920353秒，子进程峰值RSS659292KiB（约643.8MiB）。不是整Worker峰值，也不能外推整册速度。该项目Word/PDF及实际预览均保留。

真实Chromium140.0.7339.16检查上传进度、独立详情、逐页样例、方法选择、未配置禁用、设置写入/清除、原件失败重试、实际Word对PDF页面。无JS错误。设置只使用明确假密钥，再清除，未发远端请求；浏览器原值输入框为空、API只返配置布尔状态。诊断和技术信息默认折叠。截图为合成内容，见 evidence/standalone-upload-analysis/。

原有15个项目任务记录/注册哈希未变，83个历史文件实际SHA逐项未变。相关模板、产物、评论、回执和预览测试继续通过，未重识别业务文件。

## 开发期间发现并修复

首次浏览器选择option可见性条件不成立，改为检查已注册选项。随后发现子进程完成的进度曾过早显示已完成，而父进程诊断登记因不支持的role参数失败；修正登记方式与最终状态发布，保留早期失败证据，并在最终持久项目中重试分析、逐项检查诊断登记和原转换任务不变。还修复分析启动时读取旧项目导致丢失并发新增任务的竞态。最后持久化验证：五页分析SUCCEEDED、图片分析SUCCEEDED、无效PDF分析FAILED且原件/诊断保留；不是仅看退出码。

测试准备曾选到不含pytest或非服务虚拟环境的Python，另一次临时盘恰好512MiB触发应用磁盘保留门控；改用正确固定虚拟环境、独立临时2GiB测试盘，未降低应用门控或增加运行服务资源。新增哈希保护测试初次误读错误字段，按已有latest记录结构修正断言；最终68项全部通过。

## 未验证及剩余边界

- M3及兼容远端真实连通、图片推理与计费：**本轮没有调用、没有真实凭据，仍未验证**。无费用接口未核实，连接按钮只本地检查并显示尚未验证，requests=0。旧成功不能替代本轮配置验证。
- 分类、文字层可用性阈值未经统计校准，不保证OCR准确、版面完整或是否必须识别；图片覆盖为上界估计。用户需看文字样例，混合页手动选方法。SIGALRM单页提示不能保证原生操作立即响应，父进程总截止独立控制。
- 大型复杂PDF、1000页完整分析在120秒内完成、任意文章/表格/公式完整结构及整册转换未验证。不承诺所有模板适配所有内容。
- 实际Windows常见下载目录解压未执行；既有路径安全校验、ZIP完整性和Linux移位离线浏览验证不冒充Windows实测。
- 服务仅可信单人loopback开发，私有配置不在项目或下载包；不提供公网认证、多用户、自动路由或新引擎安装。本轮设置修改只影响新任务，重启中断任务不自动重发。
