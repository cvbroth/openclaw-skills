# R6 原件完整分页与工作台布局实施说明

基于R5提交9ad211c，保留识别、模板、历史评论和产物。仅独立开发服务，无OCR、云调用或生产变更。

- 原件PDF的物理页索引由已登记文件基本元数据补齐，与是否识别、评价或缓存无关。来源哈希不变；历史已处理页和评论定位保留。
- 单页预览走独立、有界的按需渲染通道，不排在识别队列末尾；单并发、单页超时、像素限制、子进程，仍受开发容器总额度约束。缓存键含原件哈希、页码、参数及渲染版本。失败可重试，前端请求令牌防止旧响应覆盖新页。
- 项目详情采用上下工作区：紧凑原件信息 → 完整宽度任务 → 完整宽度产物与排版。主操作为查看/对照，改名、回收、缓存维护与技术资料收入更多菜单。无文字稿明确禁用排版。
- 评审采用紧凑双侧工具组，文件选择与固定页码/缩放区域分开；新增页码输入、上下页和总页数。默认隐藏渲染细节。工具栏可折叠，评论、位置和滚动不重置。
- 在线支持全部物理页选择；离线显示完整索引但只展示已缓存图片，明确缺页无法离线渲染。原件与输出页独立，不推断同号对应。
- 先制作静态布局样例，再实现。合成169页PDF按页带明显页号验证1/16/23/169；覆盖缓存、失败、快速切页、源变化、边界与评论。真实浏览器桌面/窄屏及移位离线验证，结果按实测记录。
