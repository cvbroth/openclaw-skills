# 上传、原件分析与引擎设置（独立开发版）

本轮在既有 HTTP 项目、任务执行器、模板注册与评审工具上增量接入。未接入 OpenClaw，未部署生产。首页上传不会识别、排版或调用远端模型。

## 用户流程和限制

选择文件及可选项目名 → 流式上传进度百分比 → 正在检查文件 → 独立项目详情。文件发送100%不代表分析或转换完成。单文件512MiB、PDF总页数最多1000（含1000），单转换任务仍最多5页。分析不渲染整册；1000页可上传不表示1000页可一次转换。

原件保存登记后，分析失败仍保留项目和原件，可重试分析。超字节、页数、磁盘保留限制直接拒绝，临时上传清理。密码保护、无效格式、超过像素限制等留下真实原因，不填写默认页数或尺寸。图片类型依据实际解码格式。只有明确点击转换才创建识别任务；未配置或禁用引擎不能启动。

详情可选择直接提取PDF文字（无需模型）、RapidOCR本地识别、已有MiniMax M3及OpenAI兼容视觉适配器。后两者显示配置中的厂商与实际模型，未配置显示待配置。兼容协议不保证兼容所有厂商。混合PDF可分别选择页面并启动不同方法的任务，不自动逐页路由。建议只用于用户选择，不自动触发付费请求。

## 分析数据与边界

`source_info`保存原文件名、实际类型、字节数、页数或图片尺寸，以及检测状态。`analysis`独立于转换`tasks`；逐页结果保存到`diagnostics/analysis/<analysis_id>/analysis.json`并注册诊断产物，绑定原件SHA及物理页码。重试保留旧诊断，不覆盖原件。

PDF逐页读取文字层、文字样例、异常字符及图片边界信息，不调用模型：

| 分类 | 实验触发规则 | 不保证的事情 |
|---|---|---|
| text | 有文字，图片覆盖估计低于50% | 文字正确、顺序正确或无OCR需求 |
| scan | 无可提取文字，大面积图片覆盖估计至少50% | 已确认全部正文来自扫描 |
| mixed | 有文字且大面积图片覆盖至少50% | 一定需要补充OCR；可能是已带OCR层扫描 |
| blank_or_undetermined | 其他情况 | 确认空白；矢量内容等可能未分类 |

图片面积是重叠未去重的上界估计，最多记100%，不是精确版面分割。文字可用性候选要求非空白字符至少30、替代/控制字符比例低于2%；这些未经统计校准，不是准确率。小插图不自动判为需要OCR；检测到文字层也不代表文字可用。样例供用户核对。失败页及未检查页明确未知。

后台分析总硬截止120秒，子进程115秒截止、逐页5秒SIGALRM提示、2线程；SIGALRM对本地原生操作可能延迟，不能声称每页绝对5秒中止。容器沿用既有限额。进度逐页落盘，部分完成如实记录，重启活动分析标中断。最终状态仅在诊断保存及产物登记后发布，避免子进程完成冒充整体保存成功。分析与导出互斥，避免导出半份诊断。

直接提取保留PyMuPDF原生块顺序、PDF点坐标、物理页映射及原件哈希，另存Markdown和结构JSON。文字层不能保证复杂版面恢复；直接提取不渲染用于识别的图片，不产生视觉质量评价。文档排版仍按已有受支持的内容结构及模板，质量、评语、诊断不进入正文。处理前验证原件SHA，变化则停止。

## 私有配置与任务快照

`/engines`是独立服务设置页面。基础配置继续使用`deploy/standalone-http.example.json`的schema；私有覆盖保存于服务数据根的`private/engines.json`，version=1、目录700、文件600，原子替换。它不在项目、Git或导出包中。设置支持显示名称、厂商、服务地址、模型、超时、启用及密钥写入/替换/清除。已有适配器协议固定；本地固定模型不能通过更改名称更换权重，不提供引擎安装功能。

密钥只显示是否配置，接口不回传原值；输入保存后清空，不写浏览器持久存储。保留模式可沿用原服务端环境变量引用，显式清除覆盖并阻止回退到旧环境密钥。地址校验拒绝内嵌认证、查询串及片段。日志不记录请求正文或密钥。

点击启动时冻结非敏感配置和凭据，任务只持久保存脱敏快照；实际凭据短期保留在服务进程内存、通过子进程环境传递，完成后移除。配置变化只影响新任务。服务重启后旧任务明确中断，不自动重发远端请求；显式失败重试要求非敏感配置仍一致并使用届时有效凭据，不承诺保留已清除密钥。

连接检查不发图片、不生成文字、不请求远端。没有已验证无费用接口时显示尚未验证，本地检查仅确认依赖可用，不能冒充识别成功。本轮不提供隐式付费连通测试。远端真实推理仍须用户显式创建任务。

## 接口与迁移

- `POST /api/uploads?filename=...&project_name=...`：原始文件体、单一Content-Length，202返回project_id、analysis_id、上传/检查状态；无task_id。旧engine/pages查询不再启动转换。
- `POST /api/projects/:pid/analysis`：显式重试分析；没有本地登记原件的旧项目不可分析。
- `POST /api/projects/:pid/tasks`：`{"engine":"pdf-text","pages":[1,3]}`显式转换，其他已有引擎同形状。
- `GET /api/engines`：脱敏能力、可用性及配置状态。
- `POST /api/engines/:id`：局部更新，如`{"name":"视觉识别","key_action":"keep"}`；replace附api_key，clear不附密钥。
- `POST /api/engines/:id/test`：只返回本地验证/尚未远端验证，requests=0。

旧项目展示、评论、预览、模板快照保持；缺少原件信息显示未知，不猜测历史关联。旧上传客户端须改成上传后显式创建任务。回退前等待任务/分析终态，私有备份基础配置、覆盖文件和项目元数据；旧代码不识别新分析字段，恢复服务代码与原基础配置即可，保留新产物及历史文件，不能用旧整库覆盖新任务。移开私有覆盖可恢复基础引擎配置，但不要误恢复已清除密钥。回退涉及旧上传自动转换行为，应先停止前端提交。本轮只更新独立开发服务。
