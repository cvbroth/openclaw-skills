# 独立 HTTP 闭环验证报告（2026-10-08）

在myserver当前测评分支上，从f2a1ebeba3df430ce36971e23a037f4d0f7b99e1增量实现；外层整册未提交工作保留。先写实施说明，再实现服务/任务/引擎三层，未重设计现有模板或项目格式。访问、配置、接口及启动步骤见[使用说明](STANDALONE_HTTP.md)，脱敏实测元数据见[evidence](evidence/standalone-http-validation.json)。

## 已实现

HTTP流式上传、类型/路径/大小校验、异步独立项目、名称修改、任务逐页状态、取消、失败页显式重试、结果版本、产物下载/离线导出、回收站/恢复、持久化恢复。独立引擎适配器不生成网页或决定项目目录，管理界面不依赖特定模型。配置分组版本化，服务端环境凭据与公开快照隔离。

复用现有文件probe、进程树管理、publication校验发布、项目/产物登记、模板快照和离线评审；没有调用OpenClaw正式工具冒充独立能力。文件管理目前是**任务项目范围**，尚无独立NAS目录服务、全库索引、RAG或多人权限。生产任务自动创建项目的接入没有部署。

轻量管理页面与通用双栏评审：左右分别滚动/定位，固定顶部和评论区、窄屏切换、质量/本地/远端错误筛选、技术详情折叠。评论按目标产物哈希/位置关联，参考产物仅为上下文；空白新评论忽略、清除可持久化、历史回执追加、不静默覆盖冲突。导出包包含同份服务端评论快照，file://可读取；开发测试意见标developer-agent，真实页未填用户意见。缺Word预览明确提供下载和文档级评论，PDF有打开文件回退。
