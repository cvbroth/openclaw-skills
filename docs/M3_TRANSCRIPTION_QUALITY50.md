# M3原图转写＋逐页视觉质量自评实验入口

本入口仅用于已明确授权的隔离实验，不接生产、不调用本地OCR、不修改历史输出。代码复用 `m3_image_transcription.py` 的原PNG提交、内存凭据、逐次回执、超时和断点机制；增加独立的质量JSON解析和简单筛选页面，不增加人工审核状态系统。

## 准备、调用与断点

`m3_transcription_quality.py prepare --pdf <确切授权文件> --history-manifest <旧50页manifest> --seed <固定整数> --output <新目录>`：验证同PDF SHA；固定12/23/136，从历史未测试6–169页优先抽47页，只有不足才回用已测页。清单包含排序物理页码、历史重合和实际运行顺序（先12/23/136），抽样后不替换。历史PNG复用须SHA相同，其余仅渲染已抽页，220dpi、RGB、无alpha/注释。原件和历史只读，输出目录存在即拒绝。

调用前核对既有端点、模型、SecretRef来源、可查计费/余额；本入口不证明免费，不充值、不换账户。当前中国区官方按量价格与实际套餐/账单分开。`launch_m3_quality.sh`需要显式实验目录、已核对镜像完整ID、Gateway容器和现有secret-store模块路径；编译模块路径不稳定，版本变更后须先核对，不能凭示例伪造。只通过现有单键解析函数在内存中把凭据送入隔离客户端FIFO，不落盘、不输出、不进环境变量/命令行。只读根、非root、2CPU/2GiB、memory-swap总2GiB、bridge、无端口；这只是HTTP客户端，不是远端模型或生产Worker额度。

- `pilot`明确三请求，物理12/23/136，各自一个无历史的user消息、一张PNG和同一规范＋物理页码，不含OCR或历史评价。
- 核对实际请求中base64解码的SHA/尺寸/字节与原PNG相等，返回模型正确；至少两页成功且正文与质量JSON严格可分离，所有三页均终态。服务失败单列未判断；成功响应格式错误则阻止余批。实际小批次仍需人工检查再启动remainder，不因脚本门控就宣称完整视觉验收。
- `remainder`在上述小批次通过后，跳过已有尝试、只处理剩余47页。并发1、每次180秒，无自动重试。每页最多显式重试一次、累计尝试目录不超过60。401/403/429停止余批；已启动/失败/中断目录不无声覆盖。若断联，detached容器继续，续跑显式检查回执，不重跑整批。
- 当前不提供自动重试流程；需要时通过原有`--retry-page/--retry-reason`显式操作并保留原尝试。受60次总预算保护，不改变提示规避拒绝。

## 原文与质量分离

原始HTTP响应为response.raw.json，既有传输层的transcription.txt保留全部组合文本不改。新解析仅按明确的 `<transcription_markdown>` / `<quality_json>` 标记分割；前者原样写transcription.md，后者原样写quality.raw.txt、严格验证通过才生成quality.json。正文和质量校验独立；质量格式失败不能丢弃可明确分离的正文，也不能修补模型JSON或填默认等级。不得strip正文、纠错、重编号或以格式修复修改模型原文。字段缺失、错误页码/枚举、空正文、标记外文字等记failed-format，不填good。截断/空文本/服务错误保留原始产物，不作为低质量图片判断。

质量字段为模型自评、未经校准：overall_quality四类、suggested_action四类、可见缺陷、粗略位置、最多3条证据、high/medium/low及不确定说明；不产生0–100分或准确率。没有精确坐标则null；整图转写块不冒称已解析题干/选项。正文、质量、自评范围和来源相互独立。

## 汇总与看版

`bundle --directory ... --output <新目录> [--zip <新文件>]`保存原图、逐次响应/回执、正文/质量、content.md、structure.json、summary.md/json和简单离线index.html。按页、质量和处理状态筛选；textContent安全显示所有模型/用户文本。未判断独立显示，不建立审核表单或自动确认。

用量统计包含全部尝试，可见数字直接累计；缺失usage不填0。客户端耗时含网络，不冒称后端计算；账单未知写未知。按公开价格计算只能作为明确口径的情景估算，不能当扣账证明或外推整册费用。客户端字节一致不证明服务内部未缩放；本实验未使用detail参数或改变原图通道。

`browser_smoke_m3_quality.py`沿用开发Playwright检查全部页面的源图SHA/尺寸、文本和质量DOM相等、过滤器、无外部请求/JS错误。合成测试覆盖未判断与安全显示，不替代用户实际判断等级合理性或逐字准确性。正式任务和生产流程均未接入。
