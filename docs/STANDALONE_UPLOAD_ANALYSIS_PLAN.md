# 上传、分析与提取分离实施说明

基于19ab5f4增量，保留现有模板、版本/评论、评审与引擎适配层，生产不动。

1. 上传流式保存并登记为独立项目，移除引擎/选页参数；512MiB与基本1000页门控仍有效。无效文件也保留项目及错误，可显式重试分析；超字节/页数上限拒绝并清理，避免借失败项目绕过容量。后台分析独立于识别队列，逐页落盘、总超时120秒、单页5秒/进程2线程，按页读取文本/图片位置不渲染。记录分类的启发式局限，不自动调用模型。
2. 详情显示来源基本信息及分析进度/样例/原因；明确文字层、文字可用性和图像覆盖是不同信号。PDF直接文字提取作为无模型引擎，逐选页生成Markdown与原生坐标/结构，沿用既有产物发布与模板，不生成视觉质量结论。
3. 引擎设置复用现有配置schema与适配器，通过私有服务端overlay保存显示名称/启用与非敏感参数，私有凭据写入/替换/清除；UI只返配置状态。启动任务冻结配置与凭据，持久项目只存非敏感快照。配置影响后续任务，恢复旧配置以移除overlay实现；历史任务/产物不覆盖。连接测试默认仅本地验证/标未远端验证，不隐式发送付费请求。
4. 合成文字/扫描/带OCR层/混合/空白/异常PDF覆盖真实HTTP及浏览器；模拟远端密钥回显/配置竞态/断连，复用模板/评论/版本回归。真实云端测试不自动执行，明确未验证。私有配置/原图/正文留忽略目录，代码与脱敏报告提交推送。
