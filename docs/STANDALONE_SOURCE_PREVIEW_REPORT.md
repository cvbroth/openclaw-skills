## 实现

详情从左右窄列调整为上下全宽任务/产物区；按钮固定高度、更多菜单、中文日期、友好模板名、充分宽度的文字稿下拉框，无文字稿禁用排版。原件不再显示“未确认题目结构”等派生产物提示。评审文件/页码/缩放明确分组，原件显示物理总页数，普通界面隐藏渲染内部资料；保留折叠、专注及独立滚动。

真实浏览器发现并修复分析建议在轮询时消失导致卡片高度变化的问题；最终滚动480→480、表单节点/值保持。早期评论测试误把右侧原件切到16页后仍期望169页评论：实际169页回执存在，当前评论对象已正确变为16页；修正测试并分别验证历史评论与当前草稿。一次自动权限审批超时未执行浏览器命令，重试后执行；未放宽CSP或生产权限。
