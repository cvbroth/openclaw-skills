# 独立 HTTP 闭环实施说明（2026-10-08，先于实现）

基线f2a1ebeba3df430ce36971e23a037f4d0f7b99e1，当前测评分支干净，外层整册未提交工作保留。仅开发隔离服务，不替换生产、不加载OpenClaw插件。

模块边界：

1. HTTP/UI：标准库HTTP服务，仅绑定loopback，无账号、多用户、公网部署；流式原始文件上传，PDF/PNG/JPEG/WebP验证、大小/像素/页数上限、独立项目、重命名、下载、回收站、评论及离线导出。管理层调用任务接口，不持有特定模型提示。
2. 任务层：持久化任务状态、单队列、逐页独立子进程、截止时间与取消；启动时RUNNING/QUEUED明确转INTERRUPTED，不冒充自动恢复已完成调用。失败页显式重试，成功页复用；切换引擎创建新任务和产物版本，不覆盖历史。复用项目登记、模板加载、经过校验的产物发布，核心不依赖Agent身份或工作区。
3. 引擎层：明确输入PNG/参数→统一结果（正文、结构、质量、状态、错误、原生诊断）。本轮适配已有MiniMax原生messages协议、RapidOCR本地CPU、OpenAI兼容chat-completions视觉协议。无厂商静默切换、无自动付费重试。引擎不选择项目目录、不生成网页。

配置分组为服务限制、引擎、转换、模板，版本化JSON严格校验；只从服务环境变量读key，快照删除凭据引用；不提供浏览器编辑服务地址或密钥。地址HTTPS或显式本地mock，仅服务端可信配置；不声称兼容所有厂商。已有M3请求/原文分离规则复用为包内通用适配，不复制凭据。通用兼容API缺真实凭据时只做mock。

上传请求只落盘、验证并建立任务，推理在后台；选页默认首张，最多显式小范围，不默认整册。本轮先合成图真实RapidOCR端到端，再原册已有220dpi第12页PNG小范围；M3先合成图一次真实调用，必要真实原页限第12页一次，不扩展50页，不调用其他付费账号。用户关闭网页不停止任务；服务重启中断的页只在明确重试后再请求。

输出保留原文MD/最小结构JSON/独立质量JSON/输入尺寸与哈希/原响应。Word/PDF复用既有试题样式及成熟库，结构不支持时保留原文待核对段，不把任意文本冒充已恢复试题。质量、评论不写正文。公共模板1.0.0不修改；任务记录实际快照。默认不在正式正文显示每题来源，来源保留JSON。

评审延续已有双栏和按需资源；新增HTTP项目管理及服务端评论持久化，修复空白/清除/对照对象导致评论隐身；定位目标优先、参考关系记录为上下文。纯评论不代替人工确认，不增加审核状态系统。旧项目可显式导入开发副本，不改旧包。

验收：合成引擎/失败/超时/取消/重启/配置与泄密测试；真实上传和本地OCR、受限M3小样、实际浏览器管理及双栏评论与下载；真实与mock分别记录。服务在新容器中2CPU/4GiB无额外swap，无生产挂载/权限改动。监听127.0.0.1，用户可SSH转发访问；不开放公网。私有样例、上传、原图和响应只在忽略目录。完成推送代码、说明与脱敏报告，报告未完成项与访问方法，不自动扩大测试。
