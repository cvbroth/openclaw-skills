- `ocr_review_bundle.py`及静态HTML：稳定区域ID、原图整页/裁片、原始/当前文字、上下文/恢复依据、合并提醒保留来源；按页/风险/状态筛选、每组25项、草稿下载恢复及确认JSON下载。数据安全转义并使用textContent/value，无网络fetch。
- `build_ocr_review_bundle.py`：显式checkpoint与页范围；原图哈希校验、只读原始结果、结果层空间回归和私有包构建。`import_ocr_review.py`：校验来源/裁片/HTML模板/修订哈希、ID、目标、坐标、操作、理由及冲突；新修订和独立正文，不改原始资产或历史。
- `ocr-screening-v1.json`及示例：分组参数、范围/未知键校验、config版本/SHA纳入修订链；调整参数不抹去旧问题/确认。强制结构阻塞有安全下限，未实现的总分权重拒绝加载。保留未来视觉触发原因和确定性正常页抽样配置，没有模型调用。
- Skill及开发reference：说明真实开发入口、三维风险与未知、源图不可辨认、真实审阅者及整页确认边界；录音/FILETOOLS_INPUT/保存及知识库规则保留。
