# 实际支持与限制

| 类别 | V1 格式 | 提取行为 / 限制 |
|---|---|---|
| PDF | `.pdf` | 每页原生文字或 200 DPI OCR；有图像或原生文本少于 30 字符的页整页 OCR；保留原页码。加密/损坏文件拒绝 |
| Word | `.docx` | 按正文段落/表格 XML 顺序，内嵌图像保存；不访问外部图片。纯图像块保留但未 OCR，明确记录部分失败 |
| 文本 | `.md`, `.txt` | UTF-8/UTF-8 BOM 原文，无字符编码猜测；按非空空行分隔块定位，不执行 Markdown/HTML |
| 图片文字 | `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tif`, `.tiff` | 中英印刷文字 RapidOCR；多帧 TIFF 按 frame 页码。透明图像转换 RGB；复杂背景需人工复核 |
| 录音 | `.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg` | FFmpeg 可解码的常见音频，CPU/int8 faster-whisper；每段原始起止秒数，不提供说话人分离、校正或事实核实 |

扩展名与解析器都校验。`.doc`、`.rtf`、`.odt`、`.pptx`、`.xlsx`、`.csv`、`.heic`、视频、压缩包等不受支持，返回 UNSUPPORTED_TYPE。通用“文件”不意味着任意类型都可处理。音频可解码格式的支持不保证所有罕见 codec/损坏文件有效。

普通照片画面理解、手写、数学公式识别、复杂多栏/复杂表格结构、精确版式重建**未可靠支持**。OCR 仅提供文字与检测框/置信度；顺序采用引擎/几何顺序，不能保证复杂列正确。混合 PDF 的 logo/图像也可能触发整页 OCR，以避免忽略扫描正文；识别可能劣于直接文字，原件与页预览保留供核对。文字数量、非空结果和 SUCCEEDED 均不是扫描完整性证明。空白页、识别失败和低质量内容不得推断为没有信息。

DOCX 正文外的页眉/页脚、批注、脚注、浮动文本框、修订语义、复杂嵌套/合并表格与布局未完整恢复。图片-only 块记为未识别并保存原图；纯图像文档 FAILED，文本+图像块可能 PARTIAL。SVG/EMF/WMF 等内嵌资源仅保留，不渲染/执行；外链图片不会下载。表格第一行不假设是语义表头，输出保存行/单元格文本。

## 默认与硬上限

| 项目 | 初始值 / 边界 |
|---|---|
| 单附件 | ≤64 MiB，服务/插件均限制 |
| PDF / 多帧图片 | ≤500 页/帧 |
| 单帧图像或 PDF OCR 渲染 | ≤2400 万像素 |
| DOCX 解压总量 / 成员数 | ≤128 MiB / 10000 |
| 音频 | ≤7200 秒；大于 600 秒视为大附件 |
| 大附件页/块阈值 | >20；检查先只读前 3 页/块，音频不预先转写 |
| 内容文本 | ≤200 万字符；≤20000 段 |
| 产物图像总量 | ≤32 MiB/任务；必要资源超限记录失败/警告 |
| manifest | ≤64 MiB |
| 工具正文 | ≤12000 字符/次，返回截断标志与下一偏移 |
| 每 scope | 8 个有效附件、累计原件 1 GiB、32 个有效任务（不同会话有不同配额） |
| 同时重任务 | 1（可配 1–2） |
| 引擎线程 | 2（可配 1–8） |
| 默认任务 / 检查超时 | 3600 / 15 秒（检查最多 60 秒） |
| 子进程内存 | 4096 MiB 虚拟地址空间，Linux RLIMIT_AS；cgroup 样例另 4 GiB 服务实际内存 |
| 临时产物 TTL | 72 小时，可配；服务每小时清理终态任务 |

音频范围解码会创建 selected.wav 暂存（最大约 230 MB，原声 2 小时、16 kHz、mono、16 bit），完成后删除；失败/取消后的残留由任务 TTL 清理。不能把模型缓存/原件无限增长误认为临时任务自动清理的一部分。保留独立 state 磁盘配额与空闲告警。

模型：RapidOCR 1.4.4 wheel 带 OCR ONNX 模型，首次 Python 安装需网络，运行无须下载。Whisper 模型需管理员用 prepare_models.py 显式预下载、记录不可变 revision，服务默认 offline。small 约数百 MB 下载/缓存，部署按磁盘与内存实测；默认 int8/CPU，首次载入和重复任务耗时不同。旧 faster-whisper 1.1.1 的 requests 导入未在元数据中声明，本包补充固定 requests，pip check 不能替代引擎实际导入。

已锁 Python 顶层与实测完整依赖约束、Node package-lock 和 OpenClaw 2026.9.4。Linux/x86_64 的 wheel 安装、FFmpeg 发行包版本和 Docker 基础镜像 digest 仍需在构建验收中记录；Dockerfile 的版本 tag 不是不可变 digest，系统包不宣称已 hash-lock。不得把依赖装进检索 `.venv` 或运行中的 Gateway。

V2 路线图：MD/简单文本生成 DOCX/PDF；文档转换尽量保留版式；转换前后对字体、表格、分页、图像、手写/公式等损失分别报告。V1 不新增这些入口，原仓库 legacy 转换脚本不代表统一 V1 已支持生成/转换。
