## 实际修复

- 提取默认只生成文字；保存修订不自动生成文档。旧配置为true和部分参数仍遵守新默认，显式旧内部参数兼容。
- 统一导出窗口，支持当前及历史文字版本、模板、三种格式组合、来源范围、自动/来源分页与冲突设置；文件分区与独立预览、下载、改名、回收恢复。
- 修复补丁中残留 `saveFormat` DOM访问导致的编辑器异常，以及导出深链接在列表加载前打开、轮询重置所选版本、历史模板不可用时未回退可用选项的问题。
- 校验完整文字与分段组装一致，拒绝片段遗漏；保留同页多片段。“全部”不扩大提取范围；无映射旧稿可全文导出、范围导出拒绝；未知来源范围明确记为null及映射不完整。
- 排队时固定模板原始快照；任务/文件记录文字ID、哈希、版本、实际及请求来源页、模板哈希/快照和分页设置。取消与子进程成功同时发生时，取消仍阻止文件发布。
- 回归发现项目JSON保存共用 `.next` 文件，分析与保存并发时会相互重命名；改为各写入独立临时文件并清理，增加同步双写回归。
- 页码越界/筛选提示原在折叠评论区内，增加页码控件附近的可见提示。
- 旧接口、模板合成预览、已有项目和离线包阅读保留；不删除已有数据，不新增审核状态。
