## 实现与共享边界

* 导出窗口默认“原文直出”，明确选择 Markdown 版本、来源物理页范围和 Word/PDF。
  不要求模板发布。选择“自定义模板”后沿用现有模板和分页设置。
* `standalone/content_structure.py::parse_markdown/reading_html` 是原有阅读解析器；
  新 `standalone/markdown_direct.py::generate/write_reader_docx` 直接消费其块和行内格式，
  不经过 `structure_ocr`、题目选项组合、标题去重或文案改写。
* 新 `reading_style.py::STYLE/snapshot/emit_reading_assets` 定义共享字体链、字号、
  标题比例、行距和段距；阅读器使用生成的 CSS 与本地字体资源，Word 使用相同快照。
  原先随客户端系统变化的阅读字体现在明确为 Droid Sans Fallback 加现有 Noto 补充字体。
  正文 10.5pt（CSS 14px），行高 1.85，段落 1em；标题比例 1.6/1.35/1.15。
  Word 将 CSS 行高换算成固定磅值（正文 19.425pt），避免 Word 倍数行距受中文字体度量放大。
* A4、15mm 边距是输出纸张设置，浏览器窗口宽度、缩放、卡片边框、按钮和片段头不导出。
  阅读器卡片间距与分页纸张不能逐像素一致；字体层级、强调、原有编号及换行保持一致。
* `artifact_project.emit_viewer` 为旧资源生成独立 `reading-fallbacks.js`，复用同一解析器；
  不改写已有 Markdown、文字数据 JS、原件或导出。现有项目打开时与新离线包可获得更新后的阅读资产；
  已下载离线包需重新下载，本轮不会远程改写用户已有 ZIP。
* `format_jobs` 保留内容哈希、所选文字版本、来源范围、阅读样式/字体哈希快照、紧凑边界和每页实际尝试。
  PDF 必须由最终同一份 Word 经 LibreOffice 转换；只选一种格式仍进行同一套正文/分页验证。
  历史导出不重生成，保留原路径及不可变文件；现有显式模板 API 和旧 `/format` 兼容。

支持 H1–H3、段落、加粗、斜体、当前阅读器的列表标记、显式/普通换行及字体链覆盖的特殊字符。
列表遵循阅读器现有表示，不自动重编号、不组合相邻 A/B/C/D。图片、链接、疑似表格/含竖线内容、
代码块/HTML块、引用/分隔线、H4–H6 和其他解析诊断会明确拒绝，保留原文并提示来源页和格式原因。
这是保守边界，不能把“文件生成了”误当作完整格式支持；内联代码沿用当前阅读器的普通文字表示。

## 来源分页和失败处理

`markdown_direct.check_views` 只接受登记的单一来源物理页，拒绝缺失、越界、顺序回退、
无文字资源和跨页歧义；不以片段序号、题号、普通 `Page 99` 推断。当前版本须具备完整可靠映射，
不能通过选取部分范围绕过该版本其他片段的映射歧义；旧版本仍可独立阅读/编辑或采用模板连续排版。

同一来源页的所有片段按登记顺序合并，各来源页分别实际生成并转换验证为一页；
合并最终 Word 后再次逐页比较 PDF 正文与来源组，不以总页数相同代替来源关系校验。
范围 6–10 对应五页；“全部”只包括已登记内容，不补齐未识别的原件页。
请求不存在的来源页、正文空白和提取失败分别报错，不制造成功空白页。

默认阅读样式溢出即失败，提示来源物理页及实际所需页数。只有勾选紧凑适配后才先降段距/行距，
再以 0.5pt 步进降字号至用户可见下限。界面初值：字号不低于 10pt、行距不低于 1.3、段距不低于 0.3em；
服务允许的最低边界为 8pt/1.2/0em。记录每次尝试和最终参数，永不裁切或自动续页。
最终文件逐段核对 Word 正文、逐页核对 PDF 正文顺序，并检查缺字和页面越界；失败不发布 Word/PDF。
字体沿用既有字符覆盖检查、补充字体、嵌入及定位记录，不替换字符。

Worker：日常服务同一 Linux 镜像、Python 3.12、LibreOffice 7.4.7.2、实际 Droid/Noto 字体。
Chromium 在 Worker 宿主环境访问独立合成服务。未调用 OCR 或付费模型；真实项目只读抽查。

* 相关回归 126 项通过，覆盖模板/旧接口、HTTP、修订、字体、来源预览、分页和启动数据保护。
  行距校准后重跑原文直出专项，另有工作台回归；确切最终日志随交付包。
* 合成项目实际导出人工修订版 6–10 页，五张输出页；第6页两片段合并、原始版本单独导出、
  Word 单选、PDF 单选及两者均实际成功。正文包含加粗/斜体、①②③、⸺、📖、编号3与7及 A–D 四行。
  逐页文字、字体、越界检查通过，下载哈希与登记值一致。
* 明确超量正文触发来源第10页失败，无导出文件发布；空正文、失败页、缺映射、跨页歧义与缺资源有专项验证。
  重复/失败/取消的发布保护沿用现有不可变导出回归，任务进程取消和 detached 子进程也实际测试。
* 阅读器及导出窗口在 1366px、1024px、390px 宽度验证，原图与文字加载完成后截图，浏览器无脚本异常。
* 回归发现并修复 HTTP 任务清理可能误杀兄弟原件预览的问题：新 `standalone/scoped_child.py`
  为每项任务设置独立进程树所有者；成功和取消均不清理其他预览。不改通用 NAS 进程管理器。
