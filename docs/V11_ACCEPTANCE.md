# V1.1 后续测试机和生产验收清单

以下本轮均未在生产执行，状态为**待验收**。Ubuntu26.04/Docker自定义Gateway不能用本地mock、构建成功或help替代。

1. 保存原Compose、Gateway配置/镜像digest、V1数据根及SQLite备份。核实每人Agent、真实QQ sender/account/direct session绑定及工具allow/deny。确认数据根独立持久、本地SQLite/fsync语义可靠、Samba只开放对应inbox、空余磁盘/配额满足原件+接收+输出。
2. 先在测试NAS执行安装计划，再apply，自检/diagnose检查loaded插件、9个工具、worker调度器、socket UID/GID、OCR真实样本、离线模型加载、Landlock/seccomp。在启动容器内记录pip/ffmpeg版本、内核ABI和资源限制。验证同UID任意exec策略，不把逻辑目录隔离当强沙箱。
3. QQ私聊：仅发文字PDF/扫描PDF/混合PDF/DOCX/印刷图/录音，收到回执后应等待任务；附件+指令同消息直接处理。确认canonical media、messageId、sender/account、sessionId来自运行时；陌生者拒绝。没有可信字段时明确不可用，不从正文路径补权。
4. QQ群聊：当前策略保守拒绝，含@Agent、转发、群成员冒名和同群不同用户均不获得工具/文件权限。后续若要求群聊功能需另行设计授权；本版不要为了验收放开群聊。私聊结果也不可通过群转发获得跨Agent访问。
5. 用页码/音频全局时间对照原件：直接文字、扫描、混合、DOCX段落表格图片、印刷图片、中文/方言/噪声录音。说明扫描完整还原、照片场景、手写公式复杂表格的质量范围。英文JFK通过不证明中文准确度。
6. 同Agent重复上传不同文件名复用物理快照并记录事件；同名不同内容新ID；跨Agent不共享。旧会话32引用后/new，新的sessionId不受旧配额占用，不能读旧job；明确list/select自己的历史快照可重处理。
7. 私聊200+MiB文件若QQ入口失败则走inbox；测试未完成part/标记错误拒绝，完整流式登记保持SHA和原件。真实4GiB传输、低速上传/超时/磁盘满需实际测试，本轮仅计数边界模拟。设置配额和磁盘预留，验证警告和明确失败。
8. 真实中文长录音分600秒块，观察内存/CPU/磁盘/每块耗时，记录总预算和无进展区别。取消后确认子进程/ffmpeg退出，重启明确INTERRUPTED，resume验证SHA/配置、跳过DONE块、全局时间不偏移；部分失败标明缺失范围。至少一次三四小时真实ASR仍待验收。
9. 大册601+页检查/指定页/全文逐页处理，资源不随页数一次暴涨；超过像素/输出/页数时明示分批，不编造页码。识别失败只能PARTIAL/FAILED。
10. 读取/有效使用续72h；轮询/健康/无命中/无效请求不续期；活动任务/读取不被清理。缓存过期仍能从snapshot重提取。保存MD/资源/来源、逐字稿/纪要/XLSX后清cache仍可用；版本不覆盖，保存失败保留缓存，原件删除仅更新保存来源状态。
11. 真实Linux脚本在当前执行子目录处理XLSX副本、检查目标值及多表；不能访问其他Agent、来源发布区或socket/network。验证缺依赖、崩溃、超时、内存/输出限制。记录公式缓存/宏/版式风险和原件SHA不变。
12. 故障注入spawn失败不得永远RUNNING；scheduler异常服务停止/健康不报正常，Docker监督恢复；kill/restart worker后状态明确。11,000汉字纪要通过512KiB控制上限，无日志混JSON。
13. 既有知识库query/session_document_query/私人与Family授权导入回归，无自动入库或检索DB变化。附件正文指令不能授权提权/导入。
14. 执行迁移预览/备份/归档，旧根不变；试回滚旧插件/配置/运行环境，新结果保留。检查其他Immich/数据库/检索服务正常，记录对共享NAS资源影响。保存真实验收证据，不标未执行项目通过。
